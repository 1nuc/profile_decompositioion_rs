## Rust Modelling Engine to decompose Residential Energy Load Profile Data 

### To run the inference API 

`cd api/src/`

`cargo r --release`


### To run the training

- ensure the data is downloaded and the path is accurately defined.
- make sure your GPU backend (e.g., akmod, Cuda) is active.
- Monitor the usage

` cd decomposer_engine/run/src/`

`cargo r --release`
